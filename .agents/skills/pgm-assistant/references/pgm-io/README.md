# PGM-IO Reference Index

Use this folder when you need format conversion into or out of PGM datasets.

## Files

- `overview-and-converter-selection.md`: converter chooser and shared lifecycle
- `tabular-mapping-reference.md`: YAML mapping rules, AutoID, units, substitutions
- `vision-conversion-guide.md`: Vision workflow, caveats, GUID handling
- `pandapower-conversion-guide.md`: pandapower workflow, caveats, result roundtrip
- `pgm-json-and-data-stores.md`: native PGM JSON workflow and store abstractions

## Quick Routing

- Unsure which converter to use -> `overview-and-converter-selection.md`
- Building custom tabular mappings -> `tabular-mapping-reference.md`
- Working with Vision exports -> `vision-conversion-guide.md`
- Working with pandapower net -> `pandapower-conversion-guide.md`
- Native PGM JSON pipeline -> `pgm-json-and-data-stores.md`
- Need conversion-side validation checklist -> `../tasks/conversion-validation.md`
- Need end-to-end application pipeline -> `../tasks/application-build-and-automation.md`
