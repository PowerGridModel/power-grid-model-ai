# PGM-DS Reference Index

Use this folder when you need application-layer grid operations and graph analysis.

## Files

- `overview-and-core-objects.md`: Grid, FancyArray, GraphContainer fundamentals
- `graph-and-topology-recipes.md`: pathing, components, feeder IDs, orientation workflows
- `pgm-interface-workflow.md`: bridge between Grid and PowerGridModel calculations
- `mutations-serialization-visualizer.md`: safe mutations, merge, serialization, visualize

## Quick Routing

- Starting with Grid model usage -> `overview-and-core-objects.md`

- Need edit/serialize/visualize lifecycle -> `mutations-serialization-visualizer.md`
